## Características técnicas
- Barandilla basada en un perfil U base de 122x46mm o de 122x81mm
- Diseño minimalista.
- Sistema de montaje sencillo y limpio.
- Gran amplitud de visión una vez instalada.
## Posibilidades constructivas
- Montaje con base de fijación vertical.
- Montaje con base de fijación horizontal.
## Herrajes
- Posibilidad de colocar diferentes espesores de vidrio 66.2, 88.2, 1010.2 y 1010.4 mm.
- Perfil para facilitar el drenaje de la barandilla.
- Perfil base con ala, con mayor superficie de apoyo y tapa para ocultar los tornillos.
- Junta de EPDM clipada en el exterior del perfil para facilitar su instalación.
- Tapas laterales atornilladas.
- Tapa frontal para montajes con fijación lateral.
- Posibilidad de aplicar iluminación interior con perfil con alojamiento para tiras led.

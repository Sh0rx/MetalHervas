# FichaSerie

Tarjeta de una serie de proveedor con sus datos reales, copiados de `Proveedores/raw/<proveedor>.json` y nunca redondeados. Lleva un antetítulo con proveedor y material, el nombre de la serie, una cifra destacada (la profundidad del sistema) y una tabla corta de 3 o 4 datos que le importan al cliente: aislamiento, vidrio, acústica y estanqueidad. Termina con un enlace a la ficha completa.

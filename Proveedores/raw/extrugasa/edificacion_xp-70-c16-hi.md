# XP-70+ HI
Sistema de ventana practicable de 70 mm de canal 16 cuenta con una RPT de 34 mm y un aislamiento térmico HI en cámara, resulta un sistema de ventanas óptimo. Este sistema cuenta con aislamiento térmico compacto de poro cerrado ocupando toda la cámara.

# XP-50
Sistema de ventana practicable de 50 mm de canal europeo diseñado para lograr las mejores prestaciones con la mínima sección. Sus solo 50 mm de marco la convierten en una solución óptima tanto para obra nueva como para la rehabilitación de viviendas antiguas.

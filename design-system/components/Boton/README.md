# Boton

Un botón por acción, que empieza por un verbo. `.mh-btn-principal` («Pedir presupuesto») aparece una sola vez por pantalla. `.mh-btn-tel` muestra el número completo en `mono` para que se pueda leer y copiar aunque el enlace `tel:` no funcione. Altura mínima de 48px, pensada para el dedo. Quien lo usa pone el texto y el `href` o el manejador.

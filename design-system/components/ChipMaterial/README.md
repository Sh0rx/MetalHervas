# ChipMaterial

Filtro de material para la galería y para el catálogo: Hierro, Aluminio, PVC o Vidrio. Es un `<button>` con `aria-pressed`, y el activo se pinta en `verde-tinte`. El cuadradito de color sale de la marca: `viga` para hierro, `acero` para aluminio, `verde` para PVC y `menta` para vidrio. Siempre lleva texto; el color nunca va solo.
